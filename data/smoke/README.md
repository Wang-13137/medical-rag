# 冒烟测试数据说明

**本目录下的全部文件仅为系统冒烟测试（smoke test）使用的样例数据，不是真实医疗知识库，不可用于任何临床决策或医学参考。**

用途：

1. 让 `scripts/build_index.py` 与 `scripts/query.py` 在没有真实语料时也能跑通全流程；
2. 让 `tests/test_smoke_retrieval.py` 能断言「给定 query，Top-1 应当召回哪个片段」；
3. 作为后续评测集（准确率、幻觉率、拒答正确率）的最小验证载体。

条目特征：

- 共 20 条，覆盖慢病诊断标准、血糖血脂控制目标、用药注意事项、检验参考区间四类题材；
- 每条控制在 150 至 350 字，便于验证「标题优先切片 + 滑窗」两条分支；
- 数值均为常识性量级，未逐条核对最新指南，**不构成医学依据**。

真实知识库请由使用者自行放入 `data/raw/`，支持的格式见 `README.md`。
